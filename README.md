# Lingra Web MVP

Веб-демонстрация для русскоязычных взрослых, изучающих английский. В первом редакторском сценарии ученик учится переносить деловую встречу и подтверждать новое время.

## Запуск

Нужен Node.js 22 или новее. У приложения нет сторонних зависимостей.

```sh
npm test
npm run build
npm start
```

Откройте http://127.0.0.1:4173. После изменения исходников пересоберите сайт. Для развёртывания используйте содержимое `dist/` и HTTPS.

## Учебный поток

1. Запишите цель своими словами. Для первого занятия удобно взять «Научиться переносить встречи».
2. Ответьте на вопрос по тексту, заполните пропуск и выберите реплику. Ответы определят, какие навыки нужно потренировать перед разговором.
3. Выберите доступную веху. В курсе используются Q&A, Grammar, Shadowing, Role Play и Quiz. Для самостоятельного применения нужны ответы в разных ситуациях.
4. Вернитесь к упражнению после перезагрузки. Подтверждённые ошибки с готовым упражнением появляются в повторах.

## Границы этой версии

Каталог охватывает перенос встречи. Свободные ответы сверяются с редакторской рубрикой. Для других целей демонстрация знакомит с тем же примером. Голос использует распознавание и озвучку браузера там, где они доступны. Ответ можно проверить и исправить перед отправкой. Повтор образца проверяет совпадение слов.

Прогресс хранится в текущем браузере. После загрузки PWA кэширует интерфейс и упражнения, а голосовое распознавание зависит от браузера и сети. Серверный вход, синхронизация, ИИ-роли, обработка аудио на сервере и экспорт в Anki запланированы для пилота.
